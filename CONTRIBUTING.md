# Contributing

## Правила участия в проекте

1. Все изменения необходимо вносить в отдельной ветке.
2. Перед отправкой изменений необходимо проверить корректность файлов.
3. Коммиты должны иметь понятные и содержательные сообщения.
4. Изменения в основную ветку `main` вносятся через Pull Request.
5. Перед слиянием изменений необходимо проверить описание Pull Request.
